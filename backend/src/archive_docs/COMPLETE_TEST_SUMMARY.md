## 🐛 已修复的问题

### 认证测试修复
- **问题**: 期望403但返回401
- **原因**: HTTP状态码语义错误
- **修复**: 
  - `test_get_current_user_no_token`: 403 → 401
  - `test_create_project_no_auth`: 403 → 401
- **状态**: ✅ 已修复

### 时间线测试修复
- **问题**: 数据库NOT NULL约束失败
- **原因**: ProjectDocument缺少required字段
- **修复**: 所有测试添加`original_filename`字段
- **状态**: ✅ 已修复

- **问题**: 短句子过滤测试失败
- **原因**: 测试数据实际长度12字符，超过10字符限制
- **修复**: 调整测试数据为9字符
- **状态**: ✅ 已修复

### 知识图谱测试修复
- **问题**: fixture 'db' not found
- **原因**: conftest.py中未定义db fixture
- **修复**: 在test_knowledge_graph.py中添加本地db fixture
- **状态**: ✅ 已修复
