## 💡 架构改进

### 1. 统一的RESTful设计
所有统一模块遵循标准RESTful原则：
- 使用标准HTTP方法 (GET/POST/PUT/DELETE)
- 清晰的资源路径
- 统一的响应格式
- 完整的CRUD操作

### 2. 清晰的职责划分
每个统一模块有明确的功能边界：
- 单一职责原则
- 高内聚、低耦合
- 便于维护和扩展

### 3. 向后兼容
- 所有旧版API保留，添加"-old"后缀
- 标记为"(旧)"便于识别
- 为平滑迁移提供缓冲期

### 4. 统一响应格式
```python
{
    "success": true,
    "data": {...},
    "message": "操作成功",
    "request_id": "xxx"
}
```

## 🎯 使用示例

### 完整工作流

```bash
# 1. 创建项目
curl -X POST "http://localhost:8000/api/projects" \
  -d '{"name": "村落保护", "description": "传统村落保护项目"}'

# 2. 上传文档
curl -X POST "http://localhost:8000/api/projects/1/documents/upload" \
  -F "file=@document.pdf"

# 3. 处理文档
curl -X POST "http://localhost:8000/api/documents/process/1"

# 4. 建立知识图谱
curl -X POST "http://localhost:8000/api/kg/entities" \
  -d '{"name": "传统建筑", "type": "Architecture"}'

# 5. RAG对话
curl -X POST "http://localhost:8000/api/rag/chat" \
  -d '{"message": "总结保护措施", "project_id": 1}'

# 6. 文创分析
curl -X POST "http://localhost:8000/api/analysis/projects/1/creative"

# 7. 生成报告
curl -X POST "http://localhost:8000/api/reports/generate" \
  -d '{"project_id": 1, "report_type": "comprehensive", "format": "pdf"}'

# 8. 下载报告
curl "http://localhost:8000/api/reports/{report_id}/download"
```
