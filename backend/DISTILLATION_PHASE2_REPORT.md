### 2. 核心洞察提取 ✅

**实现文件**: `src/app/services/distillation_engine.py:114-218`

**提取逻辑**:
- **高频实体分析**: 识别出现频率≥3次的核心实体
- **领域标签统计**: 统计chunks的domain_tags
- **事件密度分析**: 分析时间线事件的分布和密集程度

**提取策略**:
1. 统计所有chunks中的key_entities和domain_tags
2. 识别高频主题（top 10实体和关键词）
3. 构建"核心关注点"洞察（基于高频实体）
4. 构建"时间线关键节点"洞察（基于事件密度）

**置信度计算**:
```python
confidence = min(len(source_chunk_ids) / 10.0, 0.95)
credibility = self._calculate_credibility(source_chunk_ids, len(top_entities))
```

- 可信度: 0.85
- 来源: 15个chunks

### 3. 经典原话提取 ✅

**实现文件**: `src/app/services/distillation_engine.py:220-308`

**提取逻辑**:
- **核心实体识别**: 提取高频实体（出现≥2次）
- **说话人过滤**: 优先提取有speaker字段的chunks（访谈记录）
- **情绪强度计算**: 基于感叹号、问号、强调词等

**情绪评分规则**:
```python
emotion_score = 0
if "！" in text or "!" in text: emotion_score += 0.3
if "？" in text or "?" in text: emotion_score += 0.2
if len(text) 50-200: emotion_score += 0.2
if 强调词 in text: emotion_score += 0.3
```

**提取策略**:
1. 找出包含核心实体且有说话人的chunks
2. 计算每个候选的情绪强度
3. 按情绪强度排序，提取top 5

**输出示例**:
- 标题: "李明说：我们村的土地流转工作进展顺利..."
- 内容: 原话文本（≤200字）
- 情绪分数: 0.8
- 可信度: 0.95（原话可信度高）

### 4. 思维模型匹配 ✅

**实现文件**: `src/app/services/distillation_engine.py:310-426`

**提取逻辑**:
- **关系模式识别**: 分析entity_relations中的关系类型
- **模型模式匹配**: 匹配预定义的4种思维模型

**支持的模型模式**:
1. **因果关系网络**: 导致、影响、引起、造成、产生
2. **层级结构**: 属于、包含、下属、管理、领导
3. **协作网络**: 合作、协同、配合、参与、共同
4. **时间演化**: 之前、之后、发展为、转变为、演变

**提取策略**:
1. 统计所有关系的relation_type
2. 对每种模型模式，检查匹配的关系数量（≥2个触发）
3. 为每个检测到的模式生成模型描述
4. 提取最多3个思维模型

**输出示例**:
- 标题: "思维模型：协作网络"
- 内容: "发现协作网络模式，共5个关系。\n关系示例：\n李明 → 合作 → 王教授\n..."
- 可信度: 基于关系数量（5个关系 → 0.9）

### 5. 案例与应用生成 ✅

**实现文件**: `src/app/services/distillation_engine.py:428-527`

**提取逻辑**:
- **案例特征识别**: 基于关键词匹配
- **质量评分**: 基于实体、时空信息、文本长度

**案例类型**:
1. **成功案例**: 成功、实现、达到、完成、成果、效果
2. **失败案例**: 失败、问题、困难、挑战、教训、失误
3. **创新案例**: 创新、首次、突破、改革、变革、探索
4. **经验总结**: 经验、总结、启示、收获、体会、感悟

**质量评分规则**:
```python
quality_score = 0
if chunk.key_entities: quality_score += 0.3        # 有实体
if chunk.temporal_context: quality_score += 0.2    # 有时间
if chunk.spatial_context: quality_score += 0.2     # 有空间
if 100 <= len(text) <= 500: quality_score += 0.3  # 长度适中
```

**提取策略**:
1. 扫描所有chunks，匹配案例关键词
2. 计算质量分数
3. 按质量排序，提取top 5

**输出示例**:
- 标题: "成功案例：张华"
- 内容: "【成功案例】\n张华通过创新的茶叶种植技术，实现了年收入翻倍..."

**缺口类型**:
1. **问题缺口**: 问题、不足、缺陷、短板、弱点、瓶颈
2. **需求缺口**: 需要、需求、希望、期待、要求、建议
3. **待办事项**: 应该、需要、建议、可以、计划、准备

**紧急度计算**:
```python
urgency = 0.9  # 立即、紧急、马上、尽快、亟需
```

**提取策略**:
1. 扫描chunks，识别缺口关键词

**输出示例**:

## 🔧 技术亮点

### 1. 渐进式提取
不依赖大模型，基于现有结构化数据即可工作：
- 有chunks → 可提取基础洞察
- 有entities → 可提取原话和模型
- 有events → 可提取趋势建议
- 数据越完整 → 提取越精准

### 2. 容错设计
```python
# JSON解析容错
key_entities = chunk.key_entities if isinstance(chunk.key_entities, list) \
               else json.loads(chunk.key_entities or "[]")

# 数据缺失容错
if not chunks:
    logger.warning("没有chunks数据")
    return []
```

### 3. 性能优化
- 批量查询：一次加载所有数据
- 内存计算：使用Counter、dict等高效数据结构
- 限制输出：每类最多提取5个，避免过载
