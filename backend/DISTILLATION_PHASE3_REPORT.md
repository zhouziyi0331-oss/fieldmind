## 🔌 API 集成

### 调用的后端接口
```
GET  /api/projects/{projectId}/distillation/stats
     → 获取统计数据

GET  /api/projects/{projectId}/distilled-units?unit_type={type}
     → 获取知识单元列表

POST /api/projects/{projectId}/distill
     → 执行蒸馏

GET  /api/distilled-units/{unitId}
     → 获取单个知识单元

GET  /api/distilled-units/{unitId}/sources
     → 获取溯源信息
```

### 数据流
```
用户操作 → 前端组件 → API调用 → 后端服务 → 数据库
   ↓                                          ↓
展示结果 ← 状态更新 ← 响应数据 ← 业务逻辑 ← 数据查询
```
