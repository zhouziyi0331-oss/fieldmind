## 🎯 核心功能

### 1. 6类知识单元提取

| 类型 | 图标 | 提取算法 | 平均产出 |
|------|------|----------|----------|
| 核心洞察 | 🔍 | 高频实体 + 事件密度 | 2-3个 |
| 经典原话 | 💬 | 实体 + 情绪 + 说话人 | 2-5条 |
| 思维模型 | 🧠 | 4种关系模式匹配 | 1-3个 |
| 案例应用 | 📚 | 关键词 + 质量评分 | 1-5个 |
| 行动建议 | ⚡ | 缺口 + 趋势 + 优先级 | 1-5个 |
| 方法论 | 📖 | 过程记录 + 参数配置 | 2个 |

- **可信度 (Credibility)**: 基于来源数量和证据强度

- 实时搜索（标题+内容）
- 可信度排序

## 📚 使用文档

### API文档
```
POST /api/projects/{id}/distill
  - 触发蒸馏
  - 返回: 统计结果

GET /api/projects/{id}/distillation/stats
  - 获取统计数据
  - 返回: total_units + breakdown

GET /api/projects/{id}/distilled-units?unit_type={type}
  - 获取知识单元列表
  - 参数: unit_type (可选)
  - 返回: units数组

GET /api/distilled-units/{id}
  - 获取单个知识单元
  - 返回: 完整信息

GET /api/distilled-units/{id}/sources
  - 获取溯源信息
  - 返回: sources数组

DELETE /api/distilled-units/{id}
  - 删除知识单元
```

### 前端路由
```
/projects/:projectId/distillation
  - 知识库主页

/projects/:projectId/distillation/:unitId
  - 知识单元详情
```
