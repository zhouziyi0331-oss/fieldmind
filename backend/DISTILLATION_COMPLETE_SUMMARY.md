## 📈 数据流

### 蒸馏流程
```
1. 用户点击"开始蒸馏"
   ↓
2. API: POST /api/projects/{id}/distill
   ↓
3. 加载结构化数据 (chunks/entities/events)
   ↓
4. 执行6类提取
   - 核心洞察: 高频实体分析
   - 经典原话: 情绪+说话人
   - 思维模型: 关系模式匹配
   - 案例应用: 关键词+质量评分
   - 行动建议: 缺口+趋势分析
   - 方法论: 过程记录
   ↓
5. 保存到数据库 (distilled_units表)
   ↓
6. 返回统计结果
   ↓
7. 前端刷新显示
```

### 查看流程
```
1. 进入知识库 → 加载统计
2. 筛选类型 → 加载列表
3. 点击单元 → 查看详情
4. 查看溯源 → 追踪来源
```
