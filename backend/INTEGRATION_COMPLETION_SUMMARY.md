## 🎯 问题解决过程

### 关键问题

1. **模型字段不匹配**
   - 问题: TimelineEvent 模型缺少 project_id, document_id 等字段
   - 解决: 更新模型定义，添加 7 个新字段

2. **SQLAlchemy 保留字冲突**
   - 问题: `metadata` 是 SQLAlchemy 保留字
   - 解决: 改名为 `extra_metadata`

3. **数据库表缺少列**
   - 问题: 表中没有 extra_metadata 列
   - 解决: `ALTER TABLE timeline_events ADD COLUMN extra_metadata JSON`

4. **事件分类不准确**
   - 问题: 87% 的事件被分类为"其他"
   - 待优化: 改进关键词匹配算法
