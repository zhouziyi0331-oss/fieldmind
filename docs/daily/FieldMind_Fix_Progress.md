### 修复任务 1: 建立异步处理工作流

#### 已完成的步骤：
1. ✅ 创建工作流设计文档 (`FieldMind_Workflow_Design.md`)
2. ✅ 创建 Celery 异步任务文件 (`app/tasks/document_tasks.py`)
3. ✅ 修改上传 API，调用 Celery 任务

#### 具体修改：
```python
# app/api/documents.py

# 导入 Celery 任务
from app.tasks.document_tasks import process_document

# 上传函数修改
if auto_process:
    if CELERY_AVAILABLE:
        # 异步处理：立即返回，后台处理
        process_document.delay(doc.id)
        return {"status": "processing"}
    else:
        # 同步处理（降级方案）
        # ... 原来的同步处理代码
```

#### 工作流程：
```
用户上传文件
    ↓
后端接收，创建记录（状态：processing）
    ↓
触发 Celery 异步任务
    ↓
后台处理（Whisper 转写/文档转换）
    ↓
更新数据库（状态：completed）
    ↓
通知前端刷新
```
