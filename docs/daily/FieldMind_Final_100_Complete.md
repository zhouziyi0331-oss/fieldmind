## 🚀 如何使用

### 1. 启动后端
```bash
cd ~/FieldMind-Rebuild/fieldmind-backend
python3 -m uvicorn app.main_simple:app --host 0.0.0.0 --port 8000 --reload
```

### 2. 编译前端
```bash
cd ~/Desktop/FieldMindApp
swift build
```

### 3. 运行应用
```bash
swift run
# 或在 Xcode 中打开
open Package.swift
```

### 4. 开始使用
1. 选择或创建项目
2. 上传调研材料
3. 使用三大核心功能：
   - 🔍 关键词检索
   - 💡 文创分析
   - 📊 业态分析

## 🎓 技术总结

### 架构清单
```
前端 (SwiftUI macOS)
├── Views/ (18个页面)
├── ViewModels/ (MVVM架构)
├── Models/ (Codable数据模型)
├── Services/ (API + 报告导出)
└── Utils/ (AppState等)

后端 (FastAPI Python)
├── API/ (40+ 端点)
├── Services/ (业务逻辑)
├── Models/ (数据模型)
├── Core/ (配置和工具)
└── Middleware/ (监控和日志)

工具集成 (33+)
├── Whisper (音视频转文字)
├── Neo4j (知识图谱)
├── ChromaDB (向量搜索)
├── Claude Opus 5 (AI分析)
└── ... (其他30个工具)
```

### 数据流
```
用户操作
  ↓
SwiftUI View
  ↓ @StateObject
ViewModel (@MainActor)
  ↓ async/await
APIService (单例)
  ↓ URLSession
FastAPI Backend
  ↓ 业务逻辑
AI 服务 / 数据库
  ↓ JSON 响应
Codable 解码
  ↓ @Published
View 自动刷新
```
