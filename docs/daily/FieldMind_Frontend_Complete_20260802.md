## 🔧 技术实现

### MVVM 架构
```
View (SwiftUI)
  ↓ @StateObject
ViewModel (@MainActor + @Published)
  ↓ async/await
APIService (单例)
  ↓ URLSession
Backend API (http://localhost:8000)
```

### 数据流
```
用户操作
  ↓
ViewModel.performAction()
  ↓ async
APIService.callAPI()
  ↓ try await
JSON 响应
  ↓ Codable 解码
Model 对象
  ↓ @Published 更新
View 自动刷新
```

### 状态管理
- `@Published` 属性自动触发 UI 更新
- `@StateObject` 保持 ViewModel 生命周期
- `AppState.shared` 全局状态（当前项目）
- 错误状态用 `showError` + `errorMessage`

## 📱 用户体验

### 典型使用流程

#### 流程 1：关键词检索
1. 用户打开"关键词检索"页面
2. 输入关键词"布依族"
3. 点击"搜索"或按回车
4. 系统显示加载状态（1-2秒）
5. 展示结果：
   - 找到 15 处提及
   - 视频1 在 00:03:25 提到"布依族的山歌..."
   - 视频1 在 00:12:40 提到"布依族的传统..."
   - 文档3 在第2段提到"布依族文化..."
6. 用户点击"相关关键词"中的"山歌"
7. 自动搜索"山歌"

#### 流程 2：文创分析
1. 用户打开"文创分析"页面
2. 输入关键词"布依族, 山歌"
3. 选择"创意模式"
4. 点击"开始分析"
5. 系统显示"AI 正在深度分析中..."（10-30秒）
6. 展示结果：
   - 文化元素：布依族山歌
   - 创意1：山歌对唱互动体验（可行性85分）
   - 创意2：山歌剧本杀（可行性75分）
   - 避免：❌ 制作山歌CD
7. 用户展开某个创意查看详情
8. 查看所需资源、风险点、实施步骤

#### 流程 3：业态分析
1. 用户打开"业态分析"页面
2. 点击"开始分析"
3. 系统显示"AI 正在分析业态..."（10-20秒）
4. 展示结果：
   - 现有业态：咖啡馆（运营中）
   - 建议1：研学基地（可行性78分）
   - 建议2：茶文化体验馆（可行性85分）
   - 协同效应分析
   - 专业建议
5. 用户展开"研学基地"查看详情
6. 查看投资、收益、风险、实施步骤
