# FieldMind 乡村调研平台 - 完整功能设计文档

**版本**: 2.0  
**日期**: 2026-08-02  
**定位**: 企业级乡村调研与运营决策平台

---

## 一、核心定位与用户画像

### 目标用户
- **乡村运营团队**：为基金会、村落提供调研与运营服务
- **非学术研究**：重点在实际落地和商业可行性
- **需要标准化工作流**：减少人工梳理时间，提高效率

### 核心价值主张
1. **大幅节约人工梳理时间**：AI 自动解析、分类、关联多格式材料
2. **方法论可复制**：将专家经验（如费孝通方法论）转化为可复用的思维模型
3. **数据驱动决策**：可视化数据看板 + 关键词深度分析
4. **在地化落地建议**：AI 分析文创可能性、业态建议，而非刻板模板
5. **持续验证迭代**：不断验证哪些方法有效、哪些无效

## 二、核心功能模块

### 模块 1：多格式知识导入系统

#### 1.1 支持的格式
- **文档类**：Word (.docx, .doc), Excel (.xlsx, .xls), PowerPoint (.pptx, .ppt), PDF, TXT, Markdown
- **视频类**：MP4, MOV, AVI, MKV, FLV
- **音频类**：MP3, WAV, M4A, AAC, FLAC
- **网页类**：在线爬取（新闻、政府文件、学术论文）
- **表格类**：CSV, Excel（包含标准化 SOP 表格）

#### 1.2 导入方式
- **拖拽上传**：大型拖拽区域，支持批量上传
- **文件夹导入**：整个文件夹拖入，自动识别所有支持的格式
- **云端同步**：（可选）支持从云盘导入
- **网络爬虫**：输入 URL 或关键词，自动采集相关资料

#### 1.3 智能解析功能
- **视频解析**：
  - 自动转写为文字（带时间戳）
  - 识别场景变化
  - 提取关键帧
  - 识别说话人（可选）
  
- **音频解析**：
  - 高精度语音转文字
  - 说话人分离
  - 情感分析（语气、停顿）
  
- **文档解析**：
  - OCR 识别（PDF、图片）
  - 表格结构化提取
  - 版式保留
  
- **PPT 解析**：
  - 提取每页内容
  - 识别图表和数据
  - 保留逻辑关系

#### 1.4 自动处理流程
1. 上传后自动排队处理
2. 实时显示处理进度
3. 完成后自动通知
4. 所有页面数据自动刷新

### 模块 2：关键词智能检索系统 ⭐核心

#### 2.1 关键词提取
- **自动提取**：上传材料后，AI 自动总结核心关键词
- **层级关键词**：
  - 一级：核心主题（如"布依族"、"民俗"、"山歌"）
  - 二级：相关概念（如"传统节日"、"婚嫁习俗"）
  - 三级：具体细节（如"六月六"、"对歌形式"）

#### 2.2 关键词检索功能
**输入一个关键词（如"民俗"），系统应返回：**

1. **关联材料列表**
   - 所有提到该关键词的文档、视频、音频
   - 按相关性排序
   
2. **精确定位**
   - **视频**：显示出现在第几分几秒，点击直接跳转
   - **音频**：显示时间点，提供播放按钮
   - **文档**：高亮显示关键词，显示上下文
   
3. **关键词时间线**
   - 该关键词在不同时间点的出现
   - 随时间的演变和变化
   - 与其他关键词的交叉出现

#### 2.3 关键词深度分析
- **关联关系图**：该关键词与其他概念的关系网络
- **频次统计**：在不同材料中的出现频率
- **情感趋势**：材料中对该关键词的态度变化
- **地理分布**：如果有位置信息，显示地理分布

### 模块 3：可视化数据看板系统 ⭐核心

**注意：可视化数据看板是核心，报告是次要输出**

#### 3.1 总览看板
- **项目统计**
  - 材料总数（按类型分类）
  - 处理进度
  - 覆盖时间范围
  - 涉及地理范围
  
- **核心关键词云**
  - 动态词云，大小表示重要性
  - 点击关键词直接进入深度分析
  
- **时间线可视化**
  - 横轴为时间，纵轴为事件密度
  - 点击可查看具体事件
  
- **关系网络图**
  - 人物、地点、事件、概念的关系网络
  - 可交互：点击节点查看详情、筛选关系类型

#### 3.2 关键词分析看板
针对某个关键词（如"布依族"），显示：
- **出现频率曲线**
- **关联材料数量**
- **地理热力图**（如果有位置数据）
- **相关概念网络**
- **时间演变趋势**

#### 3.3 业态分析看板
- **现有业态清单**
  - 咖啡馆、民宿、研学基地等
  - 运营状态、规模、特点
  
- **可能业态建议**
  - AI 基于调研数据分析的新业态可能性
  - 可行性评分
  - 所需资源和条件
  
- **文创潜力分析**
  - 在地特色元素提取
  - 文创结合点建议
  - 市场潜力评估

#### 3.4 验证看板
- **方法论验证**
  - 哪些方法论在本项目中有效
  - 哪些需要调整
  - 数据支撑和证据
  
- **假设验证**
  - 团队提出的假设
  - 验证状态（已证实/已推翻/待验证）
  - 支持证据

### 模块 4：思维模型与方法论系统 ⭐核心创新

#### 4.1 预置思维模型
**费孝通方法论 Skill**：
- **乡土中国框架**：差序格局、礼治秩序、熟人社会
- **分析维度**：
  - 社会结构分析
  - 权力关系网络
  - 经济模式识别
  - 文化符号解读
  
**其他可选方法论**：
- 人类学田野调查方法
- 社区营造方法论
- 参与式乡村发展（PRA）
- 文化人类学分析框架

#### 4.2 自定义方法论训练
**团队可以上传自己的标准化 SOP，系统将其训练成思维模型：**

1. **SOP 导入**
   - 上传团队的调研流程表格
   - 上传历史项目的成功案例
   - 上传方法论文档
   
2. **模型训练**
   - AI 学习团队的工作逻辑
   - 提炼关键步骤和判断标准
   - 形成可复用的思维模型
   
3. **模型应用**
   - 自动套用到新项目
   - 根据项目特点调整
   - 生成标准化工作流
   
4. **模型迭代**
   - 每次使用后收集反馈
   - 记录哪些步骤有效、哪些无效
   - 自动优化模型参数
   - 版本管理，可回溯

#### 4.3 思维模型组合
- **多模型并行**：同时应用费孝通方法论 + 团队自有方法论
- **模型对比**：对比不同方法论的分析结果
- **模型融合**：AI 融合多个方法论的优势

### 模块 5：在地文创与业态分析引擎 ⭐独特价值

#### 5.1 在地特色提取
**从调研材料中自动提取：**
- **文化元素**：
  - 传统技艺（如织布、染色、雕刻）
  - 民俗活动（如节日、仪式、歌舞）
  - 建筑风格（如吊脚楼、石板房）
  - 饮食文化（如特色食材、制作工艺）
  
- **自然资源**：
  - 地理特征（如梯田、溶洞、瀑布）
  - 物产资源（如茶叶、水果、药材）
  - 气候特点（如四季分明、云雾缭绕）
  
- **故事资源**：
  - 历史传说
  - 人物故事
  - 地名由来

#### 5.2 文创可能性分析 ⚠️不是刻板模板
**AI 深度思考，生成有创意的文创建议：**

**示例：布依族山歌**
- ❌ **刻板建议**："制作山歌 CD"、"山歌文创产品"、"山歌表演"
- ✅ **深度建议**：
  - "山歌对唱互动体验"：游客学习对歌，与当地人现场对唱，录制专属山歌
  - "山歌剧本杀"：将山歌融入剧本杀，用对歌推进剧情
  - "山歌疗愈空间"：结合心理疗愈，山歌冥想、情绪释放工作坊
  - "山歌 × 电音"：与当代音乐结合，制作融合专辑
  - "山歌 AR 体验"：AR 技术重现山歌场景，游客可看到虚拟歌者

#### 5.3 业态建议系统
**基于调研数据，分析可行的业态：**

**输入数据**：
- 村落位置、交通条件
- 现有资源和设施
- 人口结构和技能
- 周边竞争情况
- 目标客群画像

**输出建议**：
1. **咖啡馆/茶室**
   - 可行性评分：85/100
   - 理由：村落有优质茶叶资源，距城市 1.5 小时车程，适合周末客流
   - 建议模式：茶文化体验 + 轻食 + 手工体验
   - 预估投资：XX 万
   - 风险点：季节性客流、运营人才缺乏
   
2. **研学基地**
   - 可行性评分：78/100
   - 理由：有丰富的非遗资源，学校研学需求大
   - 建议课程：织布体验、农耕文化、自然探索
   - 需要补充：安全设施、住宿条件
   
3. **民宿集群**
   - 可行性评分：65/100
   - 理由：建筑有特色，但交通不便，市场竞争激烈
   - 建议差异化：主题民宿（如艺术家驻村、禅修主题）

#### 5.4 业态组合优化
- **协同效应分析**：咖啡馆 + 研学 + 民宿的组合效果
- **资源共享**：哪些业态可以共享人力、设施
- **客流导流**：如何通过一个业态带动其他业态

### 模块 8：报告生成系统

**注意：报告是可视化数据看板的延伸，不是核心**

#### 8.1 报告类型
**三层报告结构**：
1. **一度报告（信息整理）**
   - 事实梳理
   - 时间线汇总
   - 关键人物、地点、事件清单
   
2. **二度报告（学术分析）**
   - 应用选定的思维模型分析
   - 理论框架套用
   - 学术价值评估
   
3. **三度报告（商业推演）**
   - 业态建议
   - 文创可能性
   - 市场潜力分析
   - 风险评估

#### 8.2 报告格式
- **HTML**：可交互的网页报告，包含图表、链接
- **Markdown**：便于编辑和版本控制
- **PDF**：正式交付格式
- **PPT**：演示用途（自动生成）

#### 8.3 报告定制
- **选择数据范围**：指定时间段、特定材料
- **选择分析角度**：应用特定思维模型
- **自定义模板**：团队可上传报告模板

## 三、技术架构设计

### 3.1 前端架构（macOS 应用）
- **技术栈**：SwiftUI + Combine
- **架构模式**：MVVM
- **核心组件**：
  - 多格式文件处理器
  - 可视化图表库
  - 视频/音频播放器（带时间跳转）
  - 关键词检索引擎前端

### 3.2 后端架构
- **框架**：FastAPI（Python）
- **任务队列**：Celery + Redis
- **核心服务**：
  - 文件解析服务（视频/音频转写、OCR）
  - 知识图谱服务（Neo4j）
  - 向量搜索服务（Qdrant）
  - 思维模型训练服务
  - 业态分析引擎
  - 报告生成引擎

### 3.3 AI 模型
- **大语言模型**：
  - 主模型：Claude Opus 5（深度分析）
  - 辅助模型：Sonnet 5（快速处理）
  
- **专用模型**：
  - 语音识别：Whisper（OpenAI）
  - OCR：PaddleOCR 或 Tesseract
  - 图像理解：Claude Vision 或 GPT-4V
  
- **自训练模型**：
  - 团队方法论模型（基于 Fine-tuning）
  - 关键词提取模型
  - 业态预测模型

### 3.4 数据存储
- **关系数据库**：PostgreSQL（元数据、用户数据）
- **图数据库**：Neo4j（知识图谱、关系网络）
- **向量数据库**：Qdrant（语义搜索）
- **文件存储**：本地文件系统 + 可选云存储

## 四、核心工作流程

### 工作流 1：新项目创建
1. 创建项目（名称、描述、地理范围、时间范围）
2. 选择预置思维模型（费孝通、团队自有等）
3. 批量上传材料（拖拽文件夹）
4. 自动处理（解析、提取、关联）
5. 生成初始数据看板

### 工作流 2：关键词深度调研
1. 在数据看板中点击关键词（如"布依族"）
2. 系统展示：
   - 关联材料列表（含视频时间点）
   - 关键词时间线
   - 关系网络图
   - 深度分析结果
3. 可点击材料直接跳转查看原文/原视频
4. 可补充标注和笔记
5. 导出关键词专题报告

### 工作流 3：业态分析与决策
1. 进入业态分析看板
2. 查看现有业态梳理
3. AI 提供可能业态建议（含可行性评分）
4. 点击某个业态查看详细分析
5. 查看支持该建议的调研数据
6. 可选联网补充同类案例
7. 生成业态分析报告（给基金会/村委会）

### 工作流 4：思维模型训练与迭代
1. 上传团队的 SOP 文档和历史案例
2. AI 学习提炼方法论
3. 应用到新项目测试
4. 标注哪些步骤有效、哪些无效
5. 系统自动优化模型
6. 定期查看模型迭代报告

## 五、差异化竞争力

### vs 传统调研工具
| 维度 | 传统工具 | FieldMind |
|-----|---------|-----------|
| 材料处理 | 人工整理，耗时长 | AI 自动解析，秒级完成 |
| 关键词检索 | 简单文本搜索 | 深度语义搜索 + 视频时间点定位 |
| 方法论 | 在专家脑子里 | 可复制的思维模型 Skill |
| 输出 | Word/Excel 报告 | 可视化数据看板 + 交互式报告 |
| 迭代 | 无法验证方法有效性 | 持续验证和优化 |

### vs 通用 AI 工具（ChatGPT、Claude）
| 维度 | 通用 AI | FieldMind |
|-----|---------|-----------|
| 领域专精 | 泛用，无特定领域优势 | 专为乡村调研设计 |
| 知识管理 | 对话式，无结构化知识库 | 知识图谱 + 向量搜索 |
| 方法论 | 需要每次手动输入 | 内置方法论，自动应用 |
| 数据可视化 | 无 | 丰富的可视化看板 |
| 团队协作 | 困难 | 项目管理 + 团队共享 |

### 核心壁垒
1. **领域深耕**：专为乡村调研优化的 AI 引擎
2. **方法论资产化**：将专家经验转化为可复用模型
3. **验证闭环**：持续学习，越用越好
4. **在地洞察**：非刻板建议，真正理解在地特色

## 七、成功指标

### 效率指标
- **材料处理速度**：1 小时视频 → 5 分钟完成转写和分析
- **人工时间节约**：传统需要 2 周的材料整理 → FieldMind 1 天完成
- **关键词检索速度**：输入关键词 → 1 秒内返回结果

### 质量指标

## 九、技术挑战与解决方案

### 挑战 1：视频/音频处理成本高
**解决方案**：
- 优先级队列：紧急任务优先处理
- 增量处理：只处理关键片段
- 成本优化：使用开源模型（Whisper）而非商业 API

### 挑战 2：思维模型训练难度大
**解决方案**：
- 从简单的规则引擎开始（if-then 逻辑）
- 逐步引入 Few-shot Learning
- 长期目标：Fine-tuning 小模型

### 挑战 3：在地建议容易刻板化
**解决方案**：
- 提示词工程：强调"创新"、"结合在地特色"
- 多轮对话：AI 生成 → 人工反馈 → AI 优化
- 案例库学习：积累优秀的在地文创案例

### 挑战 4：数据隐私与安全
**解决方案**：
- 本地部署选项：敏感项目可私有化部署
- 数据加密：传输和存储均加密
- 权限管理：细粒度的访问控制
