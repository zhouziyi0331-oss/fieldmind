# FieldMind 使用指南

## 🎉 恭喜！您的 macOS 原生应用已经完成！

**FieldMind.app** 现在已经在您的桌面上了！

---

## 📍 应用位置

```
~/Desktop/FieldMind.app
```

---

## 🚀 如何启动应用

### 方法一：双击启动（推荐）

1. 在桌面找到 **FieldMind.app** 图标
2. **双击图标**即可启动

### 方法二：首次启动（如遇到安全提示）

由于应用未经过 Apple 签名，首次打开可能会看到安全提示：

**"无法打开 FieldMind.app，因为它来自身份不明的开发者"**

解决方法：
1. **右键点击** FieldMind.app
2. 选择 **"打开"**
3. 在弹出的对话框中点击 **"打开"** 按钮
4. 以后就可以正常双击打开了

---

## ⚙️ 配置 API 密钥

应用需要 **Anthropic API 密钥**才能使用 AI 功能（关键词提取、AI对话、报告生成等）。

### 选项 A：在应用内设置（推荐）

1. 启动 FieldMind 应用
2. 点击左侧菜单栏最下方的 **"设置"**
3. 在 "API设置" 部分找到 "Anthropic API密钥"
4. 输入您的 API 密钥
5. 密钥会自动保存

### 选项 B：使用环境变量

```bash
# 在终端中执行：
export ANTHROPIC_API_KEY='sk-ant-api03-你的密钥'

# 然后通过终端启动应用：
open ~/Desktop/FieldMind.app
```

### 如何获取 API 密钥？

访问：https://console.anthropic.com/
- 注册/登录账号
- 进入 API Keys 页面
- 创建新的 API 密钥

## 📚 快速入门

### 第 1 步：导入资料

1. 点击左侧菜单的 **"导入资料"**
2. **拖拽文件**到上传区域，或点击 **"选择文件"** 按钮
3. 支持的格式：TXT, MD, PDF, DOCX
4. 上传后 AI 会自动提取关键词

### 第 2 步：查看关键词

1. 点击左侧菜单的 **"关键词引擎"**
2. 查看 AI 自动提取的关键词云
3. 关键词大小表示出现频次
4. 点击关键词查看详情
5. 可以导出为 JSON 格式

### 第 3 步：AI 对话

1. 点击左侧菜单的 **"AI对话"**
2. 在输入框输入问题，例如：
   - "总结一下这些文档的主要内容"
   - "关键词'社区'出现在哪些文档中？"
   - "帮我分析数据的趋势"
3. 按 Enter 或点击发送按钮
4. AI 会基于您的数据回答问题

### 第 4 步：可视化分析

#### 数据仪表板
- 点击 **"数据仪表板"**
- 查看文件统计、关键词分布图、高频词排行
- 可导出报告

#### 知识图谱
- 点击 **"知识图谱"**
- 切换视图：网形图 / 树形图 / 时间轴
- 添加节点构建知识网络

#### 编年史
- 点击 **"编年史"**
- 按时间线查看文档
- 切换不同年份

### 第 5 步：生成报告

1. 点击左侧菜单的 **"报告生成"**
2. 输入报告标题（可选）
3. 点击 **"生成报告"** 按钮
4. AI 会自动生成完整的田野调查报告
5. 可以导出为 TXT 文件

## 💡 使用技巧

### 1. 批量上传
可以一次性拖拽多个文件到上传区域

### 2. 搜索功能
在搜索页面可以搜索文件名和文档内容

### 3. 数据导出
- 关键词：在关键词页面点击"导出"
- 图谱：在知识图谱页面点击"导出"
- 全部数据：在设置页面点击"导出所有数据"

### 4. 清空数据
在设置 → 数据管理 → 清空所有数据（谨慎操作）

## ❓ 常见问题

### Q1: 应用无法打开？
**A:** 右键点击 → "打开" → 确认（首次需要）

### Q2: 提示 API 错误？
**A:** 检查 API 密钥是否正确配置

### Q3: 关键词提取失败？
**A:** 确保：
- API 密钥已设置
- 网络连接正常
- 文档内容不为空

### Q4: 如何备份数据？
**A:** 设置 → 数据管理 → 导出所有数据

### Q5: 可以离线使用吗？
**A:** 
- 文件管理、搜索等功能可以离线使用
- AI 功能（关键词提取、对话、报告生成）需要网络连接
