# FieldMind 原生桌面应用使用说明

## 🎯 应用位置
**桌面上的 FieldMind.app** - 双击即可启动

---

## ✅ 已实现的功能

### 1. 概览 (Overview)
- 显示文件总数、关键词数量统计
- 快速操作按钮
- 最近文件列表

### 2. 材料导入 (Import)
- **拖拽上传**：直接拖文件到窗口
- **点击上传**：点击"选择文件"按钮
- 支持格式：TXT, MD, PDF, DOCX
- **自动AI提取关键词**

### 3. 关键词云 (Keywords)
- 词云可视化展示
- 按频率大小显示
- 颜色分类显示
- **搜索功能**：输入框搜索关键词
- **导出功能**：导出为JSON文件

### 4. AI对话 (Chat)
- 智能问答
- 消息历史记录
- 实时流式响应

### 5. 全文检索 (Search)
- 搜索文件和关键词
- 结果高亮显示
- 上下文片段展示

### 6. 数据仪表板 (Dashboard)
- 统计概览卡片
- **关键词类别分布图表**
- **高频词TOP 10排行**
- **时间范围选择**：本周/本月/本年
- **导出报告按钮**：导出PDF报告

### 7. 知识图谱 (Graph Explorer)
- **三种视图模式切换**：
  - 网形图 ✅
  - 树形图 ✅
  - 时间轴 ✅
- **添加节点按钮** ✅
- **导出图谱**：导出JSON格式 ✅
- 节点拖拽和交互

### 8. 编年史 (Chronicle)
- **年份选择菜单** ✅ (点击顶部年份下拉)
- 按月份分组显示
- 时间线可视化
- 文件按时间排序

### 9. 知识脉络 (Vein)
- 关键词关联关系展示
- 按类别分组
- 脉络路径追踪

### 10. 报告生成 (Report)
- AI生成分析报告
- **导出文本文件** ✅

### 11. 商业分析 (Business)
- 商业洞察分析
- 市场机会识别

### 12. 文件管理 (File Management)
- 文件列表
- **搜索文件** ✅
- **删除文件** ✅ (带确认对话框)

### 13. 设置 (Settings)
- **API密钥配置** ✅
- **数据导出** ✅
- **清空数据** ✅
- 主题设置

### 14. 帮助 (Help)
- 使用文档
- 常见问题

## 🚀 首次使用步骤

### 1. 配置API密钥
点击左侧边栏 **"设置"** → 输入您的 Anthropic API Key

### 2. 上传文件
点击 **"材料导入"** → 拖拽或选择文件 → 自动提取关键词

### 3. 查看分析
- **关键词云**：查看提取的关键词
- **数据仪表板**：查看统计图表
- **知识图谱**：可视化知识网络
- **编年史**：按时间查看文件

### 4. AI对话
点击 **"AI对话"** → 提问关于您上传内容的问题

## 🔄 如何重启应用
1. 关闭当前窗口
2. 双击桌面上的 **FieldMind.app**
3. 数据会自动加载

## ⚠️ 注意事项

### 首次打开可能遇到的问题：
如果macOS提示"无法打开"：
1. 右键点击 FieldMind.app
2. 选择"打开"
3. 点击确认

### API密钥设置：
必须在"设置"页面输入有效的 Anthropic API Key 才能使用AI功能
