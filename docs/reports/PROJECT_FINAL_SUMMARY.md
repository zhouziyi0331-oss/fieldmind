## 💡 核心能力

### 完整的数据处理流程

```
文档输入 → 向量化处理 → 智能切分 → 语义检索
    ↓
对话交互 → 上下文准备 → 材料溯源 → 提案生成
    ↓
API接口 → 前端展示
```

### 技术亮点

1. **真实向量化** - TF-IDF实现，非mock数据
2. **双模式搜索** - 语义搜索 + 关键词fallback
3. **完整溯源链** - 分析→陈述→来源→原始材料
4. **自动化提案** - 3种类型，智能内容生成
5. **沙箱隔离** - 安全执行用户代码

## 🚀 部署指南

### 快速启动

```bash
# 1. 安装依赖
cd fieldmind-backend
pip install -r requirements.txt

# 2. 初始化数据库
python init_analysis_tables_sqlalchemy.py

# 3. 启动服务
python main.py

# 4. 访问API文档
# http://localhost:8000/docs
```

### Docker部署

```bash
# 1. 构建镜像
docker build -f Dockerfile.backend -t fieldmind-backend .

# 2. 运行容器
docker-compose up -d

# 3. 查看日志
docker-compose logs -f backend
```

## 📝 API端点清单

### 核心功能 API
1. **材料溯源** `/api/source-traceback/*`
   - POST `/analyses` - 保存分析并溯源
   - GET `/analyses/{id}` - 获取分析（含溯源）
   - POST `/sources/{id}/verify` - 验证来源

2. **对话记忆** `/api/conversation-memory/*`
   - POST `/chat` - 智能对话
   - GET `/history/{project_id}` - 获取历史

3. **提案生成** `/api/proposal/*`
   - POST `/generate` - 生成提案
   - GET `/generate-html` - 生成HTML

4. **文档处理** `/api/document-processing/*`
   - POST `/process` - 处理文档
   - GET `/projects/{id}/status` - 获取状态

5. **项目管理** `/api/projects/*`
   - GET `/` - 项目列表
   - POST `/` - 创建项目
   - GET `/{id}` - 项目详情

6. **关键词搜索** `/api/keyword-search/*`
   - POST `/search` - 关键词检索
   - GET `/statistics/{project_id}` - 统计信息

### 辅助功能 API
7. **认证** `/api/auth/*`
8. **监控** `/api/monitoring/*`
9. **WebSocket** `/ws/*`

## 🎓 经验总结

### 成功经验

1. **渐进式开发** - 从核心功能到辅助功能
2. **测试驱动** - 每个功能都有完整测试
3. **双模式搜索** - 向量搜索失败时fallback到关键词
4. **绝对路径** - 避免相对路径导致的问题
5. **中文分词** - 实现2-4字词提取算法

### 遇到的挑战

1. **TF-IDF向量空间不一致** - 解决：增加关键词fallback
2. **数据库路径问题** - 解决：使用绝对路径
3. **关键词提取失败** - 解决：实现词提取算法
4. **测试数据不完整** - 解决：补充必要字段

### 技术选型

- ✅ **TF-IDF而非BERT** - 离线可用，轻量级
- ✅ **SQLite而非MongoDB** - 简单部署，关系型数据
- ✅ **FastAPI而非Flask** - 自动文档，类型检查
- ✅ **subprocess而非multiprocessing** - 更强的隔离
