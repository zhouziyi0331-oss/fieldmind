## 💡 技术决策记录

### 决策 1: 不使用 Celery
**原因**: 
- macOS 没有 Homebrew
- 安装 Redis 复杂
- 增加系统复杂度

**替代方案**: 
- 使用 Python ThreadPoolExecutor
- 更简单，无外部依赖
- 足够处理文档上传任务

**优点**:
- ✅ 不需要 Redis
- ✅ 不需要启动额外进程
- ✅ 代码更简单

**缺点**:
- ⚠️ 无法分布式扩展
- ⚠️ 进程重启会丢失任务
- ⚠️ 无法查看任务队列

**结论**: 对于当前需求足够
