## 🔧 解决的关键Bug

### Bug 1: SQLAlchemy数据库路径问题 ⭐⭐⭐
**问题：** 相对路径`./data/fieldmind.db`根据当前目录变化
**影响：** 测试数据保存到错误数据库
**解决：** 使用绝对路径
```python
DATABASE_URL = "sqlite:////Users/alwan/.../data/fieldmind.db"
```

### Bug 2: 关键词提取完全失效 ⭐⭐⭐
**问题：** `[w for w in query if len(w) > 1]` 按字符迭代
**影响：** 关键词搜索返回空结果
**解决：** 实现2-4字中文词提取算法
```python
# "布依族山歌有哪些类型？" → ['布依族山', '布依族', '山歌', '类型']
for i in range(len(text)):
    for length in [4, 3, 2]:
        word = text[i:i+length]
```

### Bug 3: TF-IDF向量空间不一致 ⭐⭐
**问题：** 保存和查询使用不同TF-IDF模型
**影响：** 相似度全部为0
**解决：** 语义搜索失败时fallback到关键词搜索

### Bug 4: Test数据缺少关键词字段 ⭐
**问题：** `result`中没有`keywords`字段
**影响：** 溯源时无法进行关键词搜索
**解决：** 在result中添加keywords字段

## 💡 技术亮点

### 1. 双模式搜索架构
```python
# 语义搜索（TF-IDF）
results = semantic_search(query, threshold=0.01)

# 失败时自动fallback到关键词搜索
if not results:
    keywords = extract_keywords(query)  # 2-4字词
    results = keyword_search(keywords)
```

### 2. 智能关键词提取
```python
# 从中文查询中提取有意义的词
text = "布依族山歌有哪些类型？"
# → ['布依族山', '布依族', '山歌', '类型']

for i in range(len(text)):
    for length in [4, 3, 2]:  # 优先长词
        word = text[i:i+length]
        if word not in keywords:
            keywords.append(word)
```

### 3. 提案自动生成流程
```
1. 收集项目数据
   ↓
2. 构建提案框架（3种类型）
   ↓
3. 填充智能内容（从分析提取）
   ↓
4. 生成Markdown/HTML
```

### 4. 溯源完整链路
```
分析结果 → 陈述提取 → 来源查找 → 原始文档
    ↓          ↓          ↓          ↓
analysis  statements  sources    chunks
_results              (相似度)  (位置)
```

## 🎓 经验总结

### 1. 数据库路径要用绝对路径
相对路径在不同工作目录下会指向不同文件，导致难以调试的问题。

### 2. 中文分词要考虑语言特性
简单的字符迭代不适用于中文，需要实现基于长度的词提取。

### 3. 测试数据要完整
缺少字段会导致功能降级，要确保测试数据结构和真实数据一致。

### 4. 向量搜索需要fallback
TF-IDF等轻量级方法可能失效，需要关键词搜索作为backup。
