### 技术亮点

5. **持久化**: 完整保存/加载功能，支持跨会话使用

### 关键设计决策

1. **标记删除 vs 物理删除**
   - FAISS 不支持直接删除
   - 采用标记删除 + `rebuild_index()` 压缩
   - 平衡性能和内存效率

2. **ID映射系统**
   - FAISS 使用整数索引
   - 我们使用字符串ID
   - 双向映射确保快速查找

3. **元数据存储分离**
   - FAISS 只存储向量
   - 元数据在 Python 中管理
   - 更灵活的过滤能力

4. **分数转换**
   - 余弦：`(dist + 1) / 2` -> [0, 1]
   - L2：`1 / (1 + dist)` -> [0, 1]
   - 点积：sigmoid 转换

### 性能特性

| 索引类型 | 构建速度 | 搜索速度 | 内存占用 | 准确率 |
|---------|---------|---------|---------|--------|
| Flat    | 快      | 慢      | 低      | 100%   |
| IVF     | 中      | 快      | 低      | ~95%   |
| HNSW    | 慢      | 最快    | 中      | ~98%   |

#### 2. 缓存抽象接口

##### 核心概念
- `CacheEntry`: 缓存条目数据类
  - key: 缓存键
  - value: 缓存值
  - timestamp: 时间戳
  - hits: 命中次数
  - query_embedding: 查询向量（语义缓存用）

- `VectorCache`: 抽象基类
  - 定义缓存接口
  - 提供统计功能
  - 支持两种缓存模式

##### 缓存策略
1. **精确匹配**: 查询向量完全相同才命中
2. **语义缓存**: 相似查询也能命中（余弦相似度 > 阈值）

#### 2. BM25 稀疏检索实现

**文件**: `bm25.py` (210 行)

##### 核心算法
BM25 (Best Matching 25) - 经典关键词检索算法

**公式**:
```
BM25(q, d) = Σ IDF(qi) * (f(qi, d) * (k1 + 1)) / (f(qi, d) + k1 * (1 - b + b * |d| / avgdl))
```

其中：
- `q`: 查询
- `d`: 文档
- `f(qi, d)`: 词 qi 在文档 d 中的频率
- `k1`: 词频饱和参数 (默认 1.5)
- `b`: 长度归一化参数 (默认 0.75)
- `|d|`: 文档长度
- `avgdl`: 平均文档长度
- `IDF(qi)`: 逆文档频率

##### 功能特性
1. **分词支持**
   - 中文：按字符分词（简单实现）
   - 英文：正则表达式分词
   - 可扩展接入 jieba 等

2. **IDF 计算**
   - 自动计算每个词的逆文档频率
   - 惩罚高频词，奖励低频词
   - 公式：`log((N - df + 0.5) / (df + 0.5) + 1)`

3. **长度归一化**
   - 平衡长短文档
   - 参数 b 控制归一化程度
   - b=0: 不归一化
   - b=1: 完全归一化

4. **核心方法**
   - `add_documents()`: 添加文档并构建索引
   - `search()`: 关键词搜索
   - `_tokenize()`: 分词
   - `_compute_idf()`: 计算 IDF
   - `_bm25_score()`: 计算 BM25 分数

#### 3. 混合检索实现

**文件**: `hybrid.py` (380 行)

##### 检索架构
```
查询 ──┬──> 密集检索 (向量) ──┐
       │                      ├──> 融合 ──> 结果
       └──> 稀疏检索 (BM25) ──┘
```

##### 三种融合策略

**1. RRF (Reciprocal Rank Fusion)**
```
RRF(d) = Σ weight / (k + rank(d))
```
- 基于排名的融合
- 不依赖原始分数
- 鲁棒性强
- **推荐使用**

**2. Linear (线性加权)**
```
Score(d) = w1 * dense_score(d) + w2 * sparse_score(d)
```
- 分数归一化后加权
- 权重可调
- 直观易懂

**3. Max (最大值)**
```
Score(d) = max(dense_score(d), sparse_score(d))
```
- 取两路的最大值
- 保守策略
- 偏向最相关的一路

##### 核心功能

1. **双路召回**
   - 密集检索：语义相似
   - 稀疏检索：关键词匹配
   - 互补优势

2. **智能融合**
   - 多种融合方法
   - 可配置权重
   - 分数归一化

3. **去重合并**
   - 自动合并重复文档
   - 保留最高分数
   - 更新排名

4. **参数控制**
   - `dense_top_k`: 密集召回数
   - `sparse_top_k`: 稀疏召回数
   - `top_k`: 最终返回数
   - 默认：召回 2×返回
