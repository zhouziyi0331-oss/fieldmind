# FieldMind Frontend

React + TypeScript 前端应用

生成时间: 2026-09-13 16:01:30

## 技术栈

- **框架**: React 18
- **语言**: TypeScript
- **构建工具**: Vite
- **路由**: React Router v6
- **数据获取**: React Query (TanStack Query)
- **状态管理**: Zustand
- **表单**: React Hook Form
- **HTTP 客户端**: Axios

## 快速开始

### 安装依赖

```bash
npm install
```

### 配置环境变量

创建 `.env` 文件:

```env
VITE_API_URL=http://localhost:8000/api/v1
```

### 启动开发服务器

```bash
npm run dev
```

应用将在 http://localhost:5173 启动

### 构建生产版本

```bash
npm run build
```

## 核心功能

- 用户管理（CRUD）
- 文档管理（编辑器）
- 项目管理
- 搜索功能
- JWT 认证
