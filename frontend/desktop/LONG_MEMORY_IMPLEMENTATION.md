# 长记忆系统实现方案

## 概述
FieldMind需要一个长记忆系统来处理大量长文档和碎片化对话，保持上下文连贯性和知识积累。

## 方案对比

### 方案1: 向量数据库 + RAG（推荐）
**技术栈**: Qdrant/Milvus + OpenAI Embeddings

**优点**:
- 语义搜索能力强
- 适合处理长文档和对话历史
- 支持相似度检索
- 可扩展性好

**架构**:
```
文档/对话 → 切块(Chunking) → 向量化(Embedding) → 存储到向量DB
查询时: 问题 → 向量化 → 相似度搜索 → 获取top-K → 注入到提示词
```

**实现要点**:
- 文档切块策略: 500-1000 tokens/chunk，带overlap
- 元数据存储: 文档ID、项目ID、时间戳、类型
- 混合检索: 向量相似度 + 关键词匹配

### 方案2: 知识图谱 + 实体链接
**技术栈**: Neo4j + NER

**优点**:
- 结构化知识表示
- 支持复杂关系推理
- 便于可视化

**架构**:
```
文档 → 实体识别 → 关系抽取 → 构建图谱
查询时: 问题 → 实体识别 → 图谱遍历 → 获取相关子图
```

### 方案3: 混合方案（最佳）
**结合方案1和方案2**

**优点**:
- RAG处理非结构化长文本
- 知识图谱处理结构化关系
- 互补增强

## 推荐实现: 混合方案

### 1. 后端API扩展

#### 1.1 向量存储API
```python
# 新增API端点
POST /api/v1/memory/embed
- 输入: 文档/对话片段
- 输出: 向量ID

GET /api/v1/memory/search
- 输入: 查询文本, top_k, 过滤条件(项目ID)
- 输出: 相关片段列表

POST /api/v1/memory/conversation/save
- 输入: 会话ID, 消息列表
- 输出: 保存成功状态
```

#### 1.2 记忆检索API
```python
POST /api/v1/chat/enhanced
- 输入: 
  - session_id
  - message
  - use_long_memory: true
  - memory_config: {
      search_depth: int,
      relevance_threshold: float,
      max_context_tokens: int
    }
- 输出: AI响应 + 引用来源
```

### 2. 前端实现

#### 2.1 长记忆配置UI
在ChatView中添加配置面板：
```swift
struct LongMemoryConfig {
    var enabled: Bool = true
    var searchDepth: Int = 10
    var relevanceThreshold: Double = 0.7
    var maxContextTokens: Int = 8000
}
```

#### 2.2 记忆可视化
显示检索到的相关上下文：
- 来源文档
- 相关对话历史
- 相关度评分

### 3. 技术细节

#### 3.1 文档处理流程
```
上传文档 → 
文本提取 → 
智能分块(按语义边界) → 
向量化 → 
存储(向量DB + 元数据) → 
知识图谱更新(实体/关系)
```

#### 3.2 对话历史管理
```
每次对话 → 
保存到本地/云端 → 
定期向量化(批处理) → 
按项目索引 → 
支持跨会话检索
```

#### 3.3 记忆召回策略
```
1. 短期记忆: 当前会话的最近N条消息
2. 中期记忆: 当前项目的近期对话(7天内)
3. 长期记忆: 向量检索所有相关文档和历史对话
4. 知识记忆: 从知识图谱获取相关实体和关系
```

## 配置建议

### 向量模型选择
1. **OpenAI text-embedding-3-large** (推荐)
   - 维度: 3072
   - 性能好，支持多语言
   
2. **BGE-M3** (开源替代)
   - 维度: 1024
   - 中文效果好
   - 可本地部署

### 数据库选择
1. **Qdrant** (推荐)
   - 易于部署
   - 性能优秀
   - 支持混合检索

2. **Milvus**
   - 功能丰富
   - 适合大规模

## 成本估算

### 云服务方案
- OpenAI Embeddings: $0.13/1M tokens
- Qdrant Cloud: $0.25/GB/月
- 估算: 10GB文档 ≈ $2.5/月

### 本地部署方案
- BGE-M3模型: 免费
- Qdrant本地: 免费
- 硬件: 16GB RAM + GPU(可选)

## 性能指标

### 目标
- 查询延迟: < 200ms (向量检索)
- 召回率: > 90%
- 精确率: > 85%
- 上下文长度: 支持32K+ tokens
