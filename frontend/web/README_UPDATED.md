# FieldMind Web Frontend

基于React + TypeScript + Vite的现代化Web前端应用。

## 技术栈

- **React 18** - UI框架
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **TailwindCSS** - 样式框架
- **React Router** - 路由管理
- **React Query** - 数据获取和缓存
- **Axios** - HTTP客户端
- **Zustand** - 状态管理
- **D3.js** - 数据可视化
- **Lucide React** - 图标库

## 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

访问 http://localhost:5173

## 核心功能

✅ 用户认证（登录/注册）  
✅ 项目管理  
✅ 文档管理  
✅ 智能分析  
✅ AI对话  
✅ 知识图谱  
✅ 时间线可视化

## 环境变量

创建 `.env` 文件：
```
VITE_API_BASE_URL=http://localhost:8000
```
